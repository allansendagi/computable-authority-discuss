# Computable Authority — Open Problems

A public discussion space for the open, unresolved design questions published
in the [Computable Authority Research Library](https://www.computableauthority.com/research)
as Design Notes — entries explicitly marked as unanswered rather than settled.

This repository holds no source code. It exists only to host public,
cumulative discussion on specific open problems, so a response is visible to
everyone rather than a private one-to-one email.

**Current open problems with a discussion thread:**

- R-09 — [Root Legitimacy for Machine-Executable Institutional Authority](https://www.computableauthority.com/research/root-legitimacy)
- R-12 — [Conserved-State Constraints: An Open Design Question](https://www.computableauthority.com/research/conserved-state-authority)

If you have a counter-argument, prior art, or a different approach to either
question, open a comment on the matching Discussion thread rather than a new
one — it keeps responses to the same problem in one place.
